# Images

This directory contains image assets used throughout the RINAMI Observation Framework documentation.

## Purpose

The images in this folder support the explanation of concepts, workflows, and research materials.

Examples include:

- Project logo
- Observation workflow diagrams
- Framework illustrations
- Knowledge structure diagrams
- Process flowcharts
- Icons used in documentation

## Naming Convention

Use descriptive filenames.

Examples:

```
logo.png
observation-workflow.png
knowledge-cycle.png
framework-overview.png
```

Use lowercase letters and hyphens (`-`) for filenames whenever possible.

## Image Guidelines

Recommended formats:

- PNG (diagrams and logos)
- SVG (vector graphics)
- JPG (photographs)

Recommended resolution:

- Documentation: 1200 px or wider
- Logo: Transparent PNG or SVG

## Notes

Images should support the documentation and improve understanding of the framework.

Avoid storing large binary files that are unrelated to the project.
