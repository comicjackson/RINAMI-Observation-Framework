## Versioning Policy

The project follows Semantic Versioning.

```
MAJOR.MINOR.PATCH
```

Example

```
1.2.3

1 = Major structural revision
2 = New features
3 = Bug fixes or documentation updates
```

---

## Release Types

### Major

Large-scale structural redesign.

Examples

- Framework redesign
- Observation methodology revision
- Repository restructuring

### Minor

New functionality.

Examples

- New observation templates
- Additional documentation
- New research modules

### Patch

Small improvements.

Examples

- Typographical corrections
- Documentation improvements
- Sample updates
- Bug fixes
