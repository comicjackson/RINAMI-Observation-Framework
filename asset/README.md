# Assets

This directory contains supplementary resources used by the RINAMI Observation Framework.

## Purpose

The assets folder stores supporting files that complement the documentation but are not part of the core source files.

Examples include:

- PDF documents
- Reference materials
- Icons
- Templates
- Sample resources
- Supporting media
- Exported documents

---

## Directory Structure

Example:

```
assets/
├── pdf/
├── icons/
├── references/
├── templates/
└── examples/
```

Subdirectories may be added as the project grows.

---

## Naming Convention

Use clear and descriptive filenames.

Examples:

```
observation-guide.pdf
framework-reference.pdf
rinami-icon.svg
sample-template.pdf
```

Use lowercase letters and hyphens (`-`) whenever possible.

---

## Recommended File Types

Documents

- PDF
- TXT
- Markdown

Graphics

- SVG
- PNG

Other

- CSV
- JSON
- ZIP (release packages only)

---

## Usage

Resources in this directory are intended to support the documentation and research activities of the RINAMI Project.

Some commercial resources, editable templates, and production files are intentionally excluded from this repository and are distributed separately.

---

## Notes

Keep this directory organized.

Avoid storing temporary files, application cache files, or unnecessary exports.
