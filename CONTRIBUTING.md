# Contributing to RINAMI Observation Framework

First of all, thank you for your interest in contributing to the RINAMI Observation Framework.

This project is an open research initiative that explores how human observation can be transformed into structured knowledge.

Every contribution, regardless of size, helps improve the framework.

---

# Our Philosophy

RINAMI values:

- Careful observation
- Clear documentation
- Logical structure
- Continuous verification
- Open collaboration

The goal is not simply to build documents, but to improve a methodology that others can understand, reproduce, and extend.

---

# Ways to Contribute

There are many ways to participate.

## Observation

- Share observation examples.
- Suggest new observation methods.
- Improve observation templates.

---

## Documentation

- Correct grammar or spelling.
- Improve explanations.
- Clarify terminology.
- Add examples.

---

# Before Contributing

Please:

- Read the documentation.
- Search existing Issues.
- Avoid duplicate proposals.
- Keep discussions constructive.

---

# Pull Requests

When submitting a Pull Request:

- Keep changes focused.
- Explain the purpose.
- Update documentation if necessary.
- Follow existing formatting.

Small Pull Requests are encouraged.

---

# Issues

Use GitHub Issues to report:

- Errors
- Ambiguous explanations
- Missing documentation
- Suggestions
- Research questions

Clear and reproducible reports are appreciated.

---

# Style Guidelines

Documentation should be:

- Clear
- Objective
- Reproducible
- Well-structured
- Easy to read

Separate:

- Observation
- Structure
- Hypothesis
- Verification

Avoid mixing these stages whenever possible.

---

# Research Principles

Contributors are encouraged to:

- Observe before interpreting.
- Distinguish facts from assumptions.
- Document uncertainty.
- Revise ideas when new evidence appears.

Scientific thinking is preferred over certainty.

---

# Code of Conduct

Please follow the project's Code of Conduct.

Treat all contributors with respect and professionalism.

Constructive disagreement is welcome.

Personal attacks are not.

---

# Questions

If you have questions, feel free to open a GitHub Discussion or Issue.

Research grows through conversation.
